# Deploy to GitHub Pages

1. Once the site files are on `main`, open [`QC-SD/Homepage` Pages settings](https://github.com/QC-SD/Homepage/settings/pages). Choose **Deploy from a branch**, select `main` and `/(root)`, and save. The default URL is `https://qc-sd.github.io/Homepage/`. [GitHub Pages publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
2. Verify `qcsd.us` in the `QC-SD` organization’s Pages settings using GitHub’s TXT record in Cloudflare. In the repository’s Pages settings, save `qcsd.us` as the custom domain. GitHub adds a `CNAME` file to `main`. Pull that change into local copies. [Domain verification](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/verifying-your-custom-domain-for-github-pages) · [Custom domain setup](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site)
3. In the active Cloudflare zone for `qcsd.us`, add four **DNS only** `A` records at `@`, one for each of `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, and `185.199.111.153`. Add a **DNS only** `CNAME` for `www` pointing to `qc-sd.github.io`. Replace conflicting web records for those names and keep the verification TXT record. [Cloudflare proxy settings](https://developers.cloudflare.com/dns/proxy-status/) · [GitHub Pages DNS records](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https)
4. After GitHub’s DNS check passes and the certificate is ready, enable **Enforce HTTPS**. Verify that `https://qcsd.us` loads and `https://www.qcsd.us` redirects to it. [GitHub Pages custom domains](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages)
